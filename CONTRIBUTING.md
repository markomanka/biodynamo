# Contributing Guidelines

> This repository is the skunkworks fork described in [SKUNKWORKS.md](SKUNKWORKS.md). Contributions here
> follow its [working rules](SKUNKWORKS.md#working-rules): pull requests inside this repository only,
> signed-off commits, and BioDynaMo's CI passing. To contribute to the official BioDynaMo, follow the
> upstream guidelines below.

You can find our contributing guidelines in our
[developer guide](https://biodynamo.org/docs/devguide/contribute/).
